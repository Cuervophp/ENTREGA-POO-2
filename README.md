# Ejercicios de Programación Orientada a Objetos (POO) - Java

Repositorio creado para el desarrollo de la segunda actividad de Programación Orientada a Objetos, basada en los ejercicios del libro *Ejercicios de programación orientada a objetos con Java y UML*. Se aplican conceptos fundamentales como clases, atributos, métodos, constructores, objetos, enumeraciones y diagramas de clases UML.

## 📂 Estructura del Repositorio

El proyecto se encuentra organizado en carpetas independientes para cada uno de los ejercicios:

* 📁 **`Ejercicio1` — Persona**

  * **Descripción:** Modelado de una persona mediante atributos que representan sus nombres, apellidos, número de documento de identidad, año y país de nacimiento, y género.
  * **Archivos:** `Persona.java`

* 📁 **`Ejercicio2` — Planeta**

  * **Descripción:** Representación de un planeta mediante sus características físicas y astronómicas, incluyendo el cálculo de su densidad y la determinación de si pertenece a los planetas exteriores.
  * **Archivos:** `Planeta.java`

* 📁 **`Ejercicio3` — Automovil**

  * **Descripción:** Modelado de un automóvil mediante sus características, velocidad actual y velocidad máxima. Incluye métodos para acelerar, desacelerar, frenar, calcular el tiempo de llegada y gestionar las multas por exceso de velocidad.
  * **Archivos:** `Automovil.java`

* 📁 **`Ejercicio4` — Figuras geométricas**

  * **Descripción:** Implementación de clases para calcular el área y el perímetro de distintas figuras geométricas: círculo, rectángulo, cuadrado, triángulo rectángulo, rombo y trapecio.
  * **Archivos:** `Circulo.java`, `Rectangulo.java`, `Cuadrado.java`, `TrianguloRectangulo.java`, `Rombo.java`, `Trapecio.java`, `PruebaFiguras.java`

* 📁 **`Ejercicio5` — Cuenta bancaria**

  * **Descripción:** Modelado de una cuenta bancaria con información del titular, tipo de cuenta, saldo y porcentaje de interés mensual. Incluye operaciones de consignación, retiro, consulta del saldo y aplicación de intereses.
  * **Archivos:** `CuentaBancaria.java`

## 📚 Conceptos de POO Aplicados

* **Clases:** Representan entidades como personas, planetas, automóviles, figuras geométricas y cuentas bancarias.
* **Atributos:** Almacenan las características y el estado de cada objeto.
* **Métodos:** Definen las operaciones y comportamientos de las clases.
* **Constructores:** Inicializan los atributos de los objetos al momento de su creación.
* **Objetos:** Se crean instancias de las clases para probar sus funcionalidades.
* **Enumeraciones (`enum`):** Representan conjuntos limitados de valores, como tipos de planetas, combustibles, colores y tipos de cuenta.
* **Encapsulamiento:** Se emplean modificadores de acceso para controlar la visibilidad de atributos y métodos.
* **Modularidad:** Los ejercicios se organizan en archivos `.java` independientes, facilitando la lectura y el mantenimiento del código.
* **Diagramas UML:** Representan gráficamente las clases, sus atributos, métodos, enumeraciones y relaciones.
